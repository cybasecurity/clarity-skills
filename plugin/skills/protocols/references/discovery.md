- StackingDAO/contracts is legacy; use stackingdao-smart-contracts (row above).
- ALEX `token-wstx-v2` moves native STX. `transfer-fixed` always takes eight-decimal units; `transfer` takes `token-decimals` units, `u8` at deployment, which its DAO can change, so read it before converting. At `u8` both move `amount / 100` micro-STX, rounded down: 1 STX is `u100000000`, and an amount under 100 moves nothing and fails. Write STX postconditions and `with-stx` allowances in the converted micro-STX: an exact condition on the call amount aborts, and an upper bound on it allows 100 times the outflow. Its declared `wstx` FT never moves, so never write a condition on it. The older `token-wstx` returns `u6` from `get-decimals` yet also transfers in eight-decimal units, so never scale its amounts from `get-decimals`.
